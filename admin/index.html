Drama Content Manager

Manage your DSS TV catalog. Edits remain in this browser until you publish to GitHub. GitHub Pages updates automatically after each approved publication.

1. Connect to your repository

Use a fine-grained token restricted to this repository. Token is held only in this browser tab's memory; never committed to GitHub. Anyone with this token can modify the selected repository, so keep it private. This editor URL is not password-protected.

2. Dramas

Connect GitHub to load dramas.

3. Edit drama

Select a drama or create a new entry.

4. Preview before approval

Check the title, review and poster before publishing. The website will not change until you approve.

Load a drama to preview.

4. Publish changes

Clicking Publish writes catalog.json to your GitHub repository. Preview and approve your changes below. One click uploads a selected poster (if any) and publishes the catalog to GitHub Pages.
