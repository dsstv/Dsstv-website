DSS TV V3 — Poster Library Edition

DEPLOY:
1. Extract the ZIP.
2. Upload the extracted folder's CONTENTS (index.html, catalog.json, assets/) to the existing Netlify site. index.html must be at the published root.
3. Refresh https://dsstv.netlify.app/.

ADDING MANUALLY APPROVED POSTERS:
1. Save the approved image as JPG using the exact filename shown in catalog.json.
2. Place it in assets/posters/ (e.g. assets/posters/four-hands-two-sonatas.jpg).
3. Rezip the site contents and redeploy. The card automatically displays the image once present.
4. To add a new drama, add an entry to catalog.json using the same fields; do not place unpublished scripts or confidential production files in the public folder.

IMPORTANT:
- Poster images are deliberately NOT fabricated or automatically downloaded. Cards display designed title fallbacks until approved images are added.
- Annual lists are editorial candidates, NOT verified Top 10 rankings.
- Trending is an editorial watchlist until sourced weekly rankings are imported.
- Static site: no automatic publishing, user accounts, or server-side CMS.
